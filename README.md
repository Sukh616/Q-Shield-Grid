# ⚡ Q-Grid Shield

## AI + Quantum-Inspired Smart Grid Intelligence Platform

Q-Grid Shield is a next-generation smart-grid platform that combines Artificial Intelligence, real-time analytics, and quantum-inspired optimization to build secure, sustainable, and self-healing energy systems for future smart cities.

The platform detects electricity theft, predicts transformer failures, optimizes energy distribution using QAOA via Qiskit, and improves grid resilience during failures or disasters.

---

# 🚀 Features

## 🔍 AI-Based Power Theft Detection

* Detects abnormal electricity consumption
* Identifies meter tampering and illegal connections
* Real-time anomaly alerts using AI models

## ⚛️ Quantum-Inspired Grid Optimization

* Uses QAOA for smart energy routing
* Reduces overloads and transmission losses
* Balances electricity distribution efficiently

## 🔄 Adaptive Self-Healing Grid

* Automatically reroutes power during failures
* Detects unstable nodes in real time
* Restores grid stability dynamically

## 🌍 Smart City Monitoring Dashboard

* Interactive smart-grid visualization
* Heatmaps for:

  * theft hotspots
  * overload zones
  * blackout risk areas
  * renewable energy nodes

## 🔥 Predictive Transformer Monitoring

* Forecasts transformer overloads
* Detects overheating risks
* Predictive maintenance alerts

## 🌱 Sustainability & Carbon Tracking

* Calculates estimated CO₂ reduction
* Tracks optimized energy savings

CO_2\ Saved=(Energy\ Optimized)\times(Emission\ Factor)

## ☀️ Renewable Energy Integration

* Supports solar and wind energy nodes
* Prioritizes renewable energy usage

## 🛡️ Disaster Resilience Mode

* Handles outages during floods/storms
* Isolates damaged grid nodes
* Maintains critical infrastructure power

# ⚡ How It Works

1. Smart meters continuously send energy consumption data.
2. AI models analyze the data for anomalies and overloads.
3. Quantum-inspired optimization calculates efficient energy routing.
4. Adaptive healing reroutes electricity during failures.
5. Dashboard visualizes the entire smart-grid ecosystem in real time.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/your-username/Q-Grid-Shield.git
cd Q-Grid-Shield
```

---

## Backend Setup

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

---

## Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
